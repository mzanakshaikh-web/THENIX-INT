PUBLISH WITH GITHUB PAGES
1. Open the THENIX-INT repository.
2. Upload the CONTENTS of this folder to the repository root (not the ZIP itself).
3. If GitHub asks whether to replace existing files, confirm that you intend to replace the old website.
4. Ensure filenames are exact: index.html, style.css, app.js, manifest.json, service-worker.js.
   Do not add a trailing full stop to any filename.
5. Commit changes to the main branch.
6. In Settings > Pages, keep deployment set to Deploy from a branch, main, / (root).
7. Wait for GitHub Pages to publish, then refresh the website.
